## Completion and handoff

For each work unit: update its status, outputs, evidence, blockers and next action; run relevant validation; make a scoped descriptive commit when ready. Update the handoff before stopping. Status values must reflect actual artifacts, not plans. Record unsuccessful access attempts so successors avoid repeating them blindly.

If delegation is used, assign disjoint episode/reference IDs and separate files. Only one owner edits the site and shared task/index files. A later agent can continue serially; delegation is not a prerequisite.
